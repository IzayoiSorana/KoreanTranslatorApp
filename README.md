# 🇰🇷 韓文截圖翻譯 APP (V2 版本)

這是一個基於 Python 與 EasyOCR 開發的桌面級截圖翻譯工具。
透過全域快捷鍵，使用者可以快速框選螢幕上的任何韓文區域（特別針對遊戲畫面與 UI），系統會自動進行高精準度的文字區域檢測、翻譯，並將繁體中文完美覆蓋回原圖上。

---

## 🚀 快速入口 (Quick Start)

### 1. 安裝環境 (Installation)
專案採用虛擬環境隔離。第一次使用或開發前，請先執行：
*   **腳本**：點擊執行 `v2_install.bat`
*   **動作**：這會自動使用 pip 下載並安裝 PyTorch, EasyOCR, deep-translator, PyQt6 等必要依賴。

### 2. 啟動程式 (Run)
*   **腳本**：點擊執行 `v2_run.bat`
*   **動作**：這會呼叫專案環境的 Python 啟動 `v2_main.py`。程式會在背景靜默執行，您會看到一個黑色的終端機視窗用來顯示 Debug 訊息。

### 3. 如何使用 (Usage)
1. 在任何畫面按下全域快捷鍵 **`Win + Shift + Q`**。
2. 畫面會瞬間凍結並變暗，滑鼠游標轉為十字準心。
3. 拖曳滑鼠左鍵框選想要翻譯的韓文區域。
4. 放開左鍵後，系統即會自動進行 OCR 辨識與翻譯合成（後續模組開發中）。
5. 欲取消截圖，請按 `滑鼠右鍵` 或 `Esc 鍵`。
