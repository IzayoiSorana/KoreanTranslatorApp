# 🇰🇷 韓文截圖翻譯 APP 工作流程 (Workflow)

這個應用程式從使用者按下快捷鍵，到最終產出翻譯圖片，背後經歷了六個主要的工作流程。以下是詳細的運作原理解析：

## 1. 初始化與背景待命 (Initialization & Standby)
- **環境檢查**：當您執行 `run.bat` 時，程式會先檢查系統是否具備 Tesseract OCR 引擎，並確保擁有**韓文 (`kor`)** 與 **英文 (`eng`)** 兩個語言辨識模型。
- **全域監聽**：程式透過 `pynput` 套件在作業系統背景註冊一組全域快捷鍵 **`Win + Shift + Q`**，並進入隱藏待命狀態，不會干擾您的日常操作。

## 2. 畫面擷取 (Screen Capture)
- **觸發截圖**：按下快捷鍵後，程式會瞬間拍下一張當前全螢幕的快照，並在畫面上鋪上一層半透明的黑色遮罩，將游標轉為十字型。
- **框選區域**：使用者透過滑鼠左鍵拖曳出一個矩形框來指定要翻譯的區域。
- **中斷機制**：若使用者改變主意，隨時可以按下**滑鼠右鍵**或鍵盤的 **`Esc` 鍵** 來取消截圖。
- **裁切暫存**：放開左鍵後，程式會將被框選的區域裁切下來，儲存為一張暫存圖片 (`temp_capture.png`)。

## 3. 光學字元辨識 (OCR - Optical Character Recognition)
- **雙語辨識**：程式將裁切好的圖片交由 `pytesseract` 處理，並明確指示使用 `lang='kor+eng'`（韓文+英文）雙引擎進行辨識。這能避免純英文字母被強制解讀為亂碼韓文。
- **精準定位**：辨識結果不僅包含文字，還會回傳每個單字在圖片上的**精確座標 (X, Y)** 與**寬高 (Width, Height)**。

## 4. 文字處理與翻譯 (Text Processing & Translation)
- **文字重組**：程式會根據座標，將同一行的文字組合起來。為了修復 OCR 引擎常在韓文字母間加入多餘空白的缺點，系統會將韓文緊密連接，但若是連續的英文字母則會聰明地保留空格。
- **純英文防護**：如果系統發現這一整句**全部都是英數字或符號 (ASCII)**，就會觸發防護機制，**跳過翻譯步驟**，直接保留原文，確保遊戲術語或英文名稱不會被破壞。
- **雲端翻譯**：對於包含韓文的句子，程式會透過 `deep-translator` 呼叫 Google 翻譯 API (轉為 `zh-TW` 繁體中文)。
- **容錯機制**：若遇到網路不穩或 API 限制，翻譯模組內建 **3 次自動重試**機制，以大幅降低 `[翻譯失敗]` 的機率。

## 5. 影像合成與繪製 (Image Synthesis & Rendering)
- **安全繪圖**：翻譯全部完成後，程式啟動 `QPainter` 繪圖引擎，開始在原本的截圖上「作畫」。
- **覆蓋原文**：在原本韓文的座標位置上，畫上一塊稍微半透明（透明度 94%）的白底方塊，藉此遮蓋掉原本的韓文字，同時畫上極細的灰色邊框以增加立體感。
- **動態字體縮放 (防重疊)**：
  - 程式會先根據方塊高度設定一個預設字體大小。
  - 接著計算翻譯出來的繁體中文會佔據多大空間。
  - **如果字體太大超出了白底框框，程式會自動把字級一級一級往下縮小**，直到文字能完全塞進框內為止。
  - 若縮到極限還是稍微溢出，程式會反過來**擴大白底背景的範圍**，確保文字永遠清晰可見，不會與背景的圖案或相鄰的文字重疊打架。

## 6. 檢視與儲存 (Viewing & Saving)
- **彈出視窗**：所有文字都繪製完畢後，程式會呼叫出一個標準的 Windows 視窗 (`TranslatedImageViewer`)，裡面展示著這張嶄新的合成翻譯圖片。
- **一般視窗控制**：這是一個標準視窗，具備右上角的縮小、放大與關閉按鈕，您可以暫時把它縮小到工具列，晚點再回來看。
- **存檔功能**：視窗下方配有 **「💾 儲存這張翻譯圖片」** 按鈕，點擊後可將這張翻譯好的圖片永久儲存為 PNG 格式，方便日後查閱或分享。
