# 🏗️ 韓文截圖翻譯 APP V2 (Architecture & Interface Spec)

這份文件是本專案的「大腦索引與介面合約」。未來開發或維護任何功能時，AI Agent 或工程師皆須以本文件定義的 Input/Output (I/O) 為準，確保各個模組能夠像樂高積木一樣完全獨立運作與抽換。

---

## 1. 專案總覽與架構流程
本系統採用「高內聚、低耦合」的模組化設計。主程式 (`v2_main.py`) 僅作為協調者 (Coordinator)，負責把資料從一個模組傳遞給下一個模組。

**資料流向 (Data Flow)：**
`使用者快捷鍵` ➔ **[截圖模組]** ➔ `原圖影像` ➔ **[OCR模組]** ➔ `文字與座標` ➔ **[翻譯模組]** ➔ `翻譯後文字與座標` ➔ **[繪圖模組]** ➔ `合成圖片` ➔ **[檢視器]** ➔ `UI/存檔`

---

## 2. 模組介面合約 (Module Interfaces)

為確保開發獨立性，以下嚴格定義每個模組必須接收的輸入 (Input) 與必須產出的輸出 (Output)。

### 🧩 模組 A：截圖遮罩模組 (`CaptureOverlay`)
負責處理多螢幕凍結、半透明遮罩、滑鼠框選與取消機制。
*   **Input (觸發條件)**：接收到快捷鍵 `Win+Shift+Q` 的觸發訊號。
*   **Output (產出資料)**：
    *   回傳型態：`QPixmap` 
    *   內容：使用者框選出來的「局部原圖影像」。(註：不用回傳全螢幕，只回傳目標區域以節省後續 OCR 效能)

### 🧩 模組 B：字元辨識模組 (`OCREngine`)
負責將圖片中的韓文/英文字母抓出，並定位其四角座標。未來若要將 EasyOCR 抽換成 PaddleOCR，只需替換此模組，確保 Output 格式一致即可。
*   **Input (接收資料)**：接收來自 [模組 A] 的 `QPixmap` 影像。
*   **Output (產出資料)**：
    *   回傳型態：`List[dict]` (字典陣列)
    *   內容格式：
        ```json
        [
            {
                "bbox": [[x1, y1], [x2, y1], [x2, y2], [x1, y2]],  // 四角多邊形座標
                "text": "새로운 싱글 모드",                           // 原始文字
                "confidence": 0.98                                 // AI 辨識信心度
            }
        ]
        ```

### 🧩 模組 C：翻譯與防護模組 (`Translator`)
負責判斷是否為純英文（防護機制）以及呼叫雲端 API 進行翻譯。
*   **Input (接收資料)**：接收來自 [模組 B] 的 `List[dict]` 資料。
*   **Output (產出資料)**：
    *   回傳型態：`List[dict]` (在原本的字典中新增翻譯欄位)
    *   內容格式：
        ```json
        [
            {
                "bbox": [...],
                "text": "새로운 싱글 모드",
                "translated_text": "新的單人模式"   // 新增此欄位
            }
        ]
        ```

### 🧩 模組 D：影像合成繪圖模組 (`ImageRenderer`)
純粹的視覺處理引擎，負責在原圖上畫白底與自動縮放字體，完全不涉及網路或辨識邏輯。
*   **Input (接收資料)**：
    1.  原圖影像 (`QPixmap`)
    2.  帶有翻譯結果的座標資料 (`List[dict]` 來自模組 C)
*   **Output (產出資料)**：
    *   回傳型態：`QPixmap`
    *   內容：一張已完美覆蓋上繁體中文的全新合成影像。

### 🧩 模組 E：檢視與儲存模組 (`ResultViewer`)
負責將最終結果展示給使用者，並提供存檔功能。
*   **Input (接收資料)**：接收來自 [模組 D] 的合成 `QPixmap` 影像。
*   **Output (產出行動)**：彈出具備標準視窗控制（最大化、縮小）的 GUI 介面，並處理使用者的 `.png` 儲存請求。

---

## 3. 開發規範與約定
1. **無狀態化 (Stateless)**：模組 B, C, D 內部不應保存跨次截圖的狀態。給它什麼輸入，它就生出對應的輸出。
2. **防呆處理**：如果 [模組 B] 辨識不到任何文字，應提早回傳空陣列，主程式接收到後應直接終止流程並提示使用者，不需再將空資料往後傳給翻譯模組。
